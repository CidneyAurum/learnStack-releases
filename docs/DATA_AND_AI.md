# 数据与 AI 使用说明

本说明介绍当前测试版的主要数据流和使用边界，不代表模型供应商的隐私承诺，也不表示已经完成独立安全审计。

## 数据保存在哪里

账号、已同步资料、知识内容和团队数据由 learnStack 后端处理。个人离线草稿先保存在手机本机，联网后按同步状态提交；本机保存不等于已经完成服务端同步。

当前后端由服务电脑通过 HTTPS 隧道提供。网络请求会经过承载该域名与隧道的基础设施服务；它与后续是否向外部模型发送内容是两件事。

个人学习记录仅本人可见，团队管理者不因管理权限获得读取他人个人学习记录的权限。团队内容按成员身份和角色控制访问；团队到个人的受控引用需在线授权，不等同于将团队原文复制为个人离线资料。

## AI 使用什么服务

每个账号独立配置自己的 OpenAI 兼容模型服务，包括 HTTPS Base URL、协议、模型名称及 API Key。APK 不内嵌生成／视觉模型或供应商共享密钥，未配置时不会回落到共享生成密钥。

API Key 仅在配置弹窗中临时输入。明确保存后，经 HTTPS 交给后端加密保管；不进入手机持久存储、普通任务或导出，也不会在配置读取接口中回显。模型配置仅本人可管理。

你可以先填写 HTTPS 服务地址与临时密钥，再明确点击“获取模型”，无需提前填写模型名称。此次请求只由后端向对应供应商获取模型列表，不保存输入的配置或临时密钥，不生成内容，不发送学习材料，也不改变已有配置、授权或任务。获取成功后可搜索列表，分别选择问答模型和可选视觉模型，再明确保存；不支持列表时可以手动填写。列表只反映供应商返回的名称，不证明模型的生成或视觉能力可用。

已有配置留空密钥时，仅在本次服务地址与原配置相同时，后端才能在本人权限内复用原密钥获取列表；更换地址必须重新输入密钥，不会将旧密钥发送到新地址。临时密钥、列表和获取错误仅保留在当前弹窗内存，关闭弹窗或账号变化时清除；修改地址、密钥或协议会使旧列表及其请求失效。

发起 AI 问答或授权材料处理时，完成该任务所需的内容会发送到你配置的模型供应商；按需选择的知识内容及会话上下文也可能成为输入。请先核对服务地址、供应商条款、费用、数据留存与训练使用政策；learnStack 不假定所有 API 都零留存或免费，也不保证任意模型服务均兼容。

## 你可以怎样控制

- 可不配置模型，继续保存、阅读和人工整理。
- 材料保存到后端与外部 AI 处理分别控制；请先确认目标空间与处理授权。
- 自动建议和推送提醒可以分别关闭；显式提问或请求处理仍按你的操作发起。
- 模型配置可以修改或删除；配置变化会使依赖旧配置的授权与任务失效，旧请求不会自动套用新配置。
- AI 提出的内容需要核对，正式知识由本人确认或通过团队审核；AI 不拥有审批、邀请或修改成员权限的权力。
- 个人内容发布到团队前需要明确确认；不要上传你无权分享的资料。

## 删除、撤权与反馈

应用提供资料、模型配置及账号的数据管理入口。来源删除或权限撤销会影响依赖它的引用和衍生内容；相关物理清理可能异步完成。删除前请先阅读页面的影响说明，确认需要保留的个人资料已按权限导出。

退出团队或被撤权后，服务器会拒绝后续读取；已被其他人看见、手动截图或另行导出的内容无法远程追回。团队内容不应通过公开反馈或截图再次传播。

GitHub Issue 是公开的。报告问题时只保留复现所需的最少信息，不上传密码、密钥、邀请凭证、账号资料、私人材料、完整对话或他人信息。请使用自行编写的无敏感样例。
