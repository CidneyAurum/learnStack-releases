## 0.2.0 beta

[固定版本发布页](https://github.com/CidneyAurum/learnStack-releases/releases/tag/v0.2.0-beta.1) · 应用版本 0.2.0（版本号 11）

- 问答支持围绕学习目标管理独立任务，可改名、归档和恢复；其他任务的固定版本消息需明确选择、预览并授权后引用，不自动混入历史。
- 收集按待整理、处理中、待确认、已归档继续推进，保存／同步状态单独显示；详情按核对原文、选择整理方式、预览确认推进，并在有对应记录时打开处理进度、待确认预览与已归档知识。
- 问题中的“整理为案例”先选择手动填写、按已记录行动整理，或个人问题中的 AI 起草；保留实际行动、结果、条件与来源，缺少结果不会虚构成功。正式知识仍由本人确认或团队审核。
- 案例库可按标题查找，查看条件、做法和验证信息后记录本次实践；归档、阅读和他人有效反馈不自动等于本人掌握。
- 失败时说明实际可确认状态并提供当前可用的恢复入口；未知结果先查询，版本冲突先核对，不自动重放写入或模型请求。问答回看历史时保留阅读位置，模型诊断区分配置保存、模型列表与生成／视觉验证范围。
- 团队待办区分“我提交的”和“我可审核的”，支持填写并查看退回理由；普通成员不能批准，维护者不能自审，所有者自审明确记录为“作者确认”。

本轮未进行真实模型调用，不以工程样例证明模型兼容、实体手机运行、真实学生使用效果或比赛现场验收。旧版工程和模型结果不能移作本版本通过。

运行边界：Android 8.0 及以上；预览用 debug APK；手机联网，服务电脑、后端及 HTTPS 隧道需持续在线，暂不是常驻云服务；AI 需每账号自行配置兼容服务，未配置时保留保存、阅读和人工整理。应用源码仍不公开，GitHub 自动生成的 Source code 归档只包含分发仓文档。

## 0.1.9 beta

[固定版本发布页](https://github.com/CidneyAurum/learnStack-releases/releases/tag/v0.1.9-beta.1)

- 模型配置缺少信息时，点击获取或保存会给出明确校验提示，避免只有灰色按钮；获取列表前仍不要求填写模型名称。
- 地址格式、等待处理、列表请求中与服务暂不能保存密钥等状态分别说明；列表失败时仍可手动填写模型名。
- 地址校验、密钥复用和请求使用一致规则，仅忽略首尾空白；不删除内部空白和不可见字符拼接另一个目标。
- 反馈中提供的完整 HTTPS 服务地址格式合法，用户手机上原先触发阻断的实际原因仍未确定，不归因为粘贴换行。

本轮严格 Android 构建通过（94 项任务，3 分 40 秒），JVM 测试 29 项通过；API 26 模拟器上的模型配置与模型获取两类 UI 测试 15 项全部通过，耗时 26.63 秒，均无跳过、失败或错误。安装回读 APK 哈希一致，182 项冻结输入与提交版本匹配，主题和输入法恢复后正常关闭模拟器。本轮使用合成凭据与受控服务替身，没有新增真实模型生成／视觉验证，也没有重跑 API 35 或全部后端接口。

运行边界与安装方式继续见下方说明；未配置模型时保留保存、阅读和人工整理路径。不能将本轮工程验证称为实体手机、学生效果或比赛现场验收。

## 0.1.8 beta

[固定版本发布页](https://github.com/CidneyAurum/learnStack-releases/releases/tag/v0.1.8-beta.1)

本轮关注以下修复与改进，最终交付内容及验证范围以该版本发布说明为准：

- 重复注册邮箱时显示“邮箱已注册，请返回登录。”，保留输入并提供返回登录的路径。
- 登录或注册失败在当前页面显示对应错误，避免误用知识内容的版本冲突提示。
- 创建或加入团队后切换到对应空间，改善团队邀请入口的可发现性。
- 创建邀请码时明确目标团队和角色；生成后提供复制、有效期、使用限制和加入说明。
- 模型配置支持先输入 HTTPS 服务地址和临时密钥，主动获取并搜索模型列表，再选择问答模型和可选视觉模型，明确保存；获取时无需先填写模型名称，也不会自动保存或调用生成。
- 列表不可用时保留手动填写。已有配置仅在相同服务地址下允许留空密钥并复用原密钥获取列表，更换地址需要重新输入；列表成功不等于生成或视觉能力验证通过。

运行边界：Android 8.0 及以上；预览用 debug APK；手机联网，试用后端和隧道需在线；AI 需每账号自行配置兼容服务。测试样例和工程检查不代表真实用户效果或比赛现场验收已经完成。

## 安装资产如何区分

- `.apk`：手机安装包。
- `SHA256SUMS.txt`：下载资产的 SHA-256 校验和。
- 说明 ZIP／清单：以版本发布页列出的资产为准，用于获取安装说明和版本信息。
- `Source code (zip / tar.gz)`：GitHub 根据本公开文档仓库自动生成，既不是安装包，也不是应用源码。

旧版说明不能代替新版的验证结果。更新前请核对版本和发布页，不要将不同来源或签名的 APK 混用。
