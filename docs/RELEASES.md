# 版本记录

安装包、校验和与各版本的实际发布说明见 [GitHub Releases](https://github.com/CidneyAurum/learnStack-releases/releases)。本仓库只提供公开分发材料，不包含应用源码或私有开发历史。

## 0.1.8 beta

[固定版本发布页](https://github.com/CidneyAurum/learnStack-releases/releases/tag/v0.1.8-beta.1)

本轮关注以下修复与改进，最终交付内容及验证范围以该版本发布说明为准：

- 重复注册邮箱时显示“邮箱已注册，请返回登录。”，保留输入并提供返回登录的路径。
- 登录或注册失败在当前页面显示对应错误，避免误用知识内容的版本冲突提示。
- 创建或加入团队后切换到对应空间，改善团队邀请入口的可发现性。
- 创建邀请码时明确目标团队和角色；生成后提供复制、有效期、使用限制和加入说明。
- 模型配置支持先输入 HTTPS 服务地址和临时密钥，主动获取并搜索模型列表，再选择问答模型和可选视觉模型，明确保存；获取时无需先填写模型名称，也不会自动保存或调用生成。
- 列表不可用时保留手动填写。已有配置仅在相同服务地址下允许留空密钥并复用原密钥获取列表，更换地址需要重新输入；列表成功不等于生成或视觉能力验证通过。

运行边界：Android 8.0 及以上；预览用 debug APK；手机联网，试用后端和隧道需在线；AI 需每账号自行配置兼容服务。测试样例和工程检查不代表真实用户效果或比赛现场验收已经完成。

## 安装资产如何区分

- `.apk`：手机安装包。
- `SHA256SUMS.txt`：下载资产的 SHA-256 校验和。
- 说明 ZIP／清单：以版本发布页列出的资产为准，用于获取安装说明和版本信息。
- `Source code (zip / tar.gz)`：GitHub 根据本公开文档仓库自动生成，既不是安装包，也不是应用源码。

旧版说明不能代替新版的验证结果。更新前请核对版本和发布页，不要将不同来源或签名的 APK 混用。
