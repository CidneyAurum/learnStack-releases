# 安装与开始使用

## 1. 下载和安装

1. 使用 Android 8.0 及以上的手机，打开 [0.1.8 beta 发布页](https://github.com/CidneyAurum/learnStack-releases/releases/tag/v0.1.8-beta.1)。
2. 展开 **Assets**，下载 `learnStack-demo-0.1.8-debug.apk`，也可[直接下载 APK](https://github.com/CidneyAurum/learnStack-releases/releases/download/v0.1.8-beta.1/learnStack-demo-0.1.8-debug.apk)。不要下载 GitHub 自动生成的 Source code 归档来安装应用。
3. 打开 APK；如系统询问，允许当前浏览器或文件管理器安装此来源的应用，再按系统提示完成安装。
4. 打开 learnStack，确认手机可以联网，使用默认服务地址 `https://learnstack.marnhub.com`。

当前安装包是预览用 debug APK，未通过应用商店分发。请只从本仓库发布页取得安装包；发布页的 `SHA256SUMS.txt` 用于核对下载文件是否完整，不能替代来源判断。也可下载[包含安装包与说明的 ZIP](https://github.com/CidneyAurum/learnStack-releases/releases/download/v0.1.8-beta.1/learnStack-demo-0.1.8.zip)，解压后打开其中的 APK。

如果已经安装旧版，先尝试直接覆盖安装。若提示签名不一致，请停止安装并反馈，避免为解决安装错误而直接卸载；卸载可能删除尚未同步的本机资料。若提示不允许降级，请核对安装包版本。

## 2. 注册或登录

- 首次使用：输入自己的邮箱和密码，完成注册。
- 已有账号：选择登录，使用原邮箱和密码。
- 提示“邮箱已注册，请返回登录。”：返回登录即可，已输入的邮箱会保留。

请保管好自己的账号。不要在公开反馈中提供邮箱、密码或登录令牌。

## 3. 配置 AI

1. 打开 **账户** 中的模型配置。
2. 填写模型服务的 HTTPS Base URL、API Key 和模型名称，选择服务支持的 OpenAI 兼容协议（Chat Completions 或 Responses）。
3. 保存配置，使用检查功能核对服务，再到 **问答** 发起提问。

配置需要与供应商实际支持的协议和模型一致，并非所有声称兼容的服务都已验证。未配置时，仍可使用保存、阅读和人工整理等不依赖模型的路径；AI 请求不会自动使用开发者的共享密钥。

密钥会通过 HTTPS 交给后端加密保管，不会持久保存到手机本地。详见 [数据与 AI 使用说明](DATA_AND_AI.md)。

## 4. 邀请别人加入学生团队

1. 创建学生团队空间后，进入该团队的 **账户 → 当前团队** 区域。
2. 由团队所有者选择 **邀请成员 · 生成邀请码**，确认目标团队及邀请角色。普通协作优先使用普通成员角色；维护者权限应按实际需要授予。
3. 生成后查看页面显示的邀请码、有效期与使用限制，按需点击复制，再自行发给受邀者。
4. 受邀者注册或登录后，打开空间选择入口，选择 **通过邀请码加入团队**，输入邀请码。

创建团队不会自动发送邀请。每个邀请码仅供 1 人加入，72 小时内有效，离开显示页面后无法找回。邀请码能赋予加入团队的资格，请只发给你希望加入的人，不要贴到公开 Issue。邀请码过期、丢失或达到使用限制时，请所有者重新生成。

## 5. 服务暂时不可用时

当前手机通过 HTTPS 隧道连接试用后端，依赖服务电脑、后端及隧道在线。打开官网不代表后端一定在线，登录、同步和 AI 功能仍需要后端可用。

- 检查手机网络和服务地址；暂时无法连接时，稍后重试。
- 个人草稿以页面显示的“本机保存／待同步／已同步／失败”等状态为准；待同步时不要卸载应用或清除应用数据。
- 不要通过关闭证书验证、改用陌生服务地址或公开密钥来排查连接问题。
- 团队资料及其受控引用需要在线访问；已失去权限的内容不能通过离线草稿恢复访问。

如果仍然失败，请在 [Issue](https://github.com/CidneyAurum/learnStack-releases/issues) 中提供版本、Android 版本、发生时间、步骤及页面提示，并先遮盖隐私信息。
