# learnStack

learnStack 官方下载与使用说明。此仓库公开测试版安装包、版本记录及使用说明；应用源码暂不公开。

learnStack 帮助你整理自学资料、记录学习问题，并将可复用的方法沉淀到案例库；学生团队也可以在课程、实验、竞赛或毕业设计中共享和审核知识。

**测试版本：0.2.0 beta · Android 8.0 及以上**

## 使用前了解

- 当前提供的是预览用 debug APK，并非应用商店正式发行版。安装包在版本发布页的 **Assets** 中，不放入本仓库的文件列表。
- 手机需要联网；当前试用后端由本机服务通过 HTTPS 隧道提供，依赖服务电脑、后端及隧道持续在线，暂不是常驻云服务。
- AI 功能需要你在账户中配置自己的 OpenAI 兼容模型服务。APK 不内嵌生成模型，也不提供共享模型密钥；模型服务可能单独收费。
- 已有账号请直接登录。注册提示邮箱已注册时，无需重复注册或卸载应用。
- 0.2.0 增加按学习目标分开的任务会话，改进收集阶段、案例整理、错误恢复和团队审核待办。任务归档、问题解决、案例有效与本人掌握分别记录。

## 你可以做什么

- **知识**：按知识目录和资料目录整理、阅读与查找内容。
- **收集**：先保存文字、资料和零碎记录，按待整理、处理中、待确认、已归档继续推进；本机保存与联网同步另行显示。
- **问答**：围绕一个学习目标开始新任务、连续追问，按需选择有权访问的知识空间；引用其他任务消息前需明确选择、预览并授权。
- **问题与案例**：记录实际尝试与结果，再选择手动填写、按已记录行动整理，或在个人问题中预览输入并授权 AI 起草；案例保留适用条件与反馈。
- **团队**：创建学生团队空间、邀请成员，分别查看本人提交和有权审核的待办；退回理由可供重新整理时核对。

AI 输出是建议，仍需核对；正式知识由本人确认或经过团队审核。测试版的功能、网络和模型兼容性可能存在限制。

0.2.0 本轮未进行真实模型调用；工程样例不代表真实模型、实体手机、真实学生使用效果或比赛现场验收已经完成。
